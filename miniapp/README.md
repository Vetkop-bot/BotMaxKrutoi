Мини приложение

SportBuddy — мини-приложение для мессенджера MAX. Помогает найти компанию для спорта: поиск встреч, создание своих встреч, список моих встреч и профиль.

Что нужно

Node.js версии 18 или новее.

Как запустить для проверки

1. Открыть терминал в папке miniapp.

2. Установить зависимости:
   npm install

3. Запустить:
   npm run dev

4. Открыть в браузере адрес, который появится в терминале

Чтобы открыть на своём телефоне: телефон должен быть в той же Wi-Fi сети, открыть адрес из строки Network в терминале.

Как собрать для размещения на хостинге

   npm run build

Готовые файлы появятся в папке dist. Именно её содержимое нужно выложить на хостинг с HTTPS.
Посмотреть собранную версию локально: npm run preview

Что стоит знать при проверке

В обычном браузере приложение работает полностью, но без функций MAX: вместо имени пользователя показывается тестовое имя, кнопка "Назад" своя, вибрации и отправки в чат нет. Эти функции работают только когда приложение открыто внутри MAX.

Встречи в приложении тестовые. Созданные встречи и записи сохраняются только в браузере на этом устройстве, другие пользователи их не видят. Сервера пока нет.
